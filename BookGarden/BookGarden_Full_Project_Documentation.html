BookGarden — Full Project Documentation

এই document-এ বর্তমান project-এর file structure, code purpose, CRUD flow, error fixes, notification system এবং PDF বানানোর নিয়ম ব্যাখ্যা করা হয়েছে।

Project summary: BookGarden একটি ASP.NET Core MVC application। এতে SQL Server/LocalDB ব্যবহার করে Category create, read, update এবং delete করা যায়। Razor Views দিয়ে UI তৈরি হয়েছে এবং Toastr দিয়ে success/error notification দেখানো হয়।

1. Project কীভাবে কাজ করে

  1. User browser থেকে URL request পাঠায়।
  2. ASP.NET Core routing request-টি নির্দিষ্ট Controller action-এ পাঠায়।
  3. Controller, ApplicationDbContext ব্যবহার করে database-এর সঙ্গে কাজ করে।
  4. Controller একটি Model বা ViewModel view-তে পাঠায়।
  5. Razor View HTML তৈরি করে browser-এ পাঠায়।
  6. CRUD সফল হলে TempData-তে message রাখা হয় এবং shared notification partial Toastr popup দেখায়।

4. Database এবং Model

Category.cs

public class Category
{
    [Key]
    public int CategoryIdentification { get; set; }

    [Required]
    [StringLength(100)]
    public string Name { get; set; } = string.Empty;

    public string? Description { get; set; } = string.Empty;

    [Range(0,100, ErrorMessage = "Range must be between 0 and 100!!")]
    public string DisplayOrder { get; set; } = string.Empty;
}
  • [Key] বলে CategoryIdentification primary key।
  • [Required] বলে Name empty হতে পারবে না।
  • [StringLength(100)] Name সর্বোচ্চ 100 characters হতে পারবে।
  • [Range(0,100)] DisplayOrder-এর range validation নির্ধারণ করে।
Note: বর্তমান code-এ DisplayOrder type string, কিন্তু [Range] সাধারণত numeric property-এর জন্য বেশি উপযুক্ত। ভবিষ্যতে এটি int করলে validation আরও নির্ভুল হবে।

ApplicationDbContext.cs

public class ApplicationDbContext : DbContext
{
    public ApplicationDbContext(DbContextOptions<ApplicationDbContext> options)
        : base(options) { }

    public DbSet<Category> Categories { get; set; }

    protected override void OnModelCreating(ModelBuilder modelBuilder)
    {
        base.OnModelCreating(modelBuilder);
        modelBuilder.Entity<Category>().HasData(
            new Category { CategoryIdentification = 1, Name = "Action", Description = "Action genre books", DisplayOrder = "1" },
            new Category { CategoryIdentification = 2, Name = "Sci-Fi", Description = "Science fiction books", DisplayOrder = "2" },
            new Category { CategoryIdentification = 3, Name = "History", Description = "History genre books", DisplayOrder = "3" }
        );
    }
}

DbSet<Category> database-এর Categories table represent করে। HasData initial seed data তৈরি করে।

[HttpPost]
[ValidateAntiForgeryToken]
public IActionResult Create(Category category)
{
    if (!string.IsNullOrEmpty(category.Name) &&
        _context.Categories.Any(c => c.Name.ToLower() == category.Name.ToLower()))
    {
        ModelState.AddModelError("", "Category name already exists!");
    }

    if (ModelState.IsValid)
    {
        _context.Categories.Add(category);
        _context.SaveChanges();
        TempData["success"] = "Category created successfully!";
        return RedirectToAction("Index");
    }

    return View(category);
}
  • POST form থেকে Category object receive করে।
  • আগে একই নাম আছে কি না check করে।
  • ModelState.IsValid হলে database-এ save করে।
  • TempData redirect-এর পর success notification দেখানোর জন্য message বহন করে।
  • Validation fail হলে entered values সহ একই view ফেরত দেয়।

Update

[HttpGet]
public IActionResult Update(int? id)
{
    if (id == null || id == 0) return NotFound();

    var category = _context.Categories.Find(id);
    if (category == null) return NotFound();

    return View(category);
}

URL-এর id দিয়ে category খুঁজে Update form-এ পাঠায়। id না থাকলে বা category না পেলে 404 Not Found দেয়।

[HttpPost]
[ValidateAntiForgeryToken]
public IActionResult Update(Category category)
{
    if (!string.IsNullOrEmpty(category.Name) &&
        _context.Categories.Any(c =>
            c.CategoryIdentification != category.CategoryIdentification &&
            c.Name.ToLower() == category.Name.ToLower()))
    {
        ModelState.AddModelError("", "Category name already exists!");
    }

    if (ModelState.IsValid)
    {
        _context.Categories.Update(category);
        _context.SaveChanges();
        TempData["success"] = "Category updated successfully";
        return RedirectToAction("Index");
    }

    return View(category);
}

নিজের record বাদ দিয়ে duplicate name check করা হয়েছে। Update() entity-এর existing record পরিবর্তন করে।

Delete করার আগে confirmation view দেখায়।

[HttpPost]
[ValidateAntiForgeryToken]
public IActionResult Delete(Category category)
{
    var categoryToDelete = _context.Categories.Find(category.CategoryIdentification);
    if (categoryToDelete == null) return NotFound();

    _context.Categories.Remove(categoryToDelete);
    _context.SaveChanges();
    TempData["success"] = "Category deleted successfully";

    return RedirectToAction(nameof(Index));
}

Hidden primary key ব্যবহার করে database থেকে সঠিক category delete করে।

6. Views এবং Razor code

Index.cshtml

@model List<BookGarden.Models.Category>

@foreach (var category in Model)
{
    <td>@category.Name</td>
    <a asp-action="Update"
       asp-route-id="@category.CategoryIdentification">Edit</a>
    <a asp-action="Delete"
       asp-route-id="@category.CategoryIdentification">Delete</a>
}

@model view-এর expected data type নির্ধারণ করে। foreach প্রতিটি category table row হিসেবে দেখায়। asp-action এবং asp-route-id সঠিক URL তৈরি করে।

আগের error: একই anchor tag-এ href="#" এবং asp-action ছিল। Anchor Tag Helper নিজে href তৈরি করে, তাই explicit href সরানো হয়েছে।

Create.cshtml

<form method="post">
    <input asp-for="Name" />
    <input asp-for="DisplayOrder" />
    <button type="submit">Create Category</button>
</form>

asp-for input-কে Model property-এর সঙ্গে bind করে। Form POST করলে controller-এর Create POST action receive করে।

Update.cshtml

<form asp-action="Update" method="post">
    <input asp-for="CategoryIdentification" type="hidden" />

</form>

Hidden primary key না পাঠালে controller বুঝতে পারত না কোন category update করতে হবে।

Delete.cshtml

<form asp-action="Delete" method="post">
    <input asp-for="CategoryIdentification" type="hidden" />

Delete confirmation view details দেখায় এবং POST submit করে। GET request দিয়ে সরাসরি database delete করা হয়নি—এটি নিরাপদ design।

11. User flow

  1. Categories menu: /Category/Index বা /Category খুলে list দেখায়।
  2. New Category: Create form খুলে; submit করলে validation, save এবং success Toastr চলে।
  3. Edit: Update page খুলে; existing data দেখায়; save করলে database update হয়।
  4. Delete: Delete confirmation page খুলে; confirm করলে category delete হয়।
  5. Cancel: user category list page-এ ফিরে যায়।
