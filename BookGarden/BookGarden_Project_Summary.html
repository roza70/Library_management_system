BookGarden Project Summary

Project development summary

1. Category list null error fix

Category controller থেকে category list view-তে পাঠানো হয়েছে। এর ফলে Razor view-এর Model আর null থাকে না।

2. Book image fix

Images/book.png file serve করার জন্য /Image static route তৈরি করা হয়েছে। Layout-এ image path ঠিক করা হয়েছে:

~/Image/book.png

3. Category Create

  • নতুন category database-এ save করার ব্যবস্থা করা হয়েছে।
  • Duplicate category name validation যোগ করা হয়েছে।
  • নতুন category তৈরি হলে success message দেখানোর ব্যবস্থা করা হয়েছে।

4. Category Update

  • Update action-এর ভুল bracket এবং structure ঠিক করা হয়েছে।
  • Category update করার জন্য Update() ব্যবহার করা হয়েছে।
  • Primary key হিসেবে সঠিক property CategoryIdentification ব্যবহার করা হয়েছে।
  • নিজের category-কে duplicate হিসেবে গণনা করা হয় না।
  • Update form view তৈরি করা হয়েছে।

5. Category Delete

  • আলাদা Delete.cshtml confirmation view তৈরি করা হয়েছে।
  • Delete করার আগে category details দেখা যায়।
  • GET action confirmation page দেখায়।
  • POST action database থেকে category delete করে।
  • Delete সফল হলে success notification দেখায়।

6. Reusable notification partial

Views/Shared/_notification.cshtml নামে একটি reusable partial view তৈরি করা হয়েছে। এটি success এবং error message handle করে।

7. Toastr notification

  • Toastr CSS এবং JavaScript layout-এ যোগ করা হয়েছে।
  • Create, Update এবং Delete সফল হলে popup notification দেখা যায়।
  • Notification partial-টি _Layout.cshtml-এ রাখা হয়েছে।
  • তাই যেকোনো page থেকে TempData["success"] অথবা TempData["error"] ব্যবহার করা যাবে।

8. DRY rule

Notification markup একাধিক view-তে না লিখে shared partial view ব্যবহার করা হয়েছে। ফলে একই code পুনরায় লেখার প্রয়োজন নেই।
